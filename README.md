## 📌 Project Overview

The Mobile Phone Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI. It provides insights into mobile phone sales, brand performance, customer ratings, customer demographics, and payment methods.

The dashboard helps analyze sales performance and understand customer purchasing patterns through interactive visualizations.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Number of Brands
- Total Mobile Models
- Total Sales Amount
- Average Customer Ratings
- Average Customer Age

### 2. Brand Analysis
- Apple
- Samsung
- Xiaomi
- OnePlus
- Vivo

### 3. Sales Analysis
- Monthly Units Sold
- Total Sales Amount by Brand
- Units Sold by Payment Method

### 4. Interactive Filters
- Brand-wise filtering
- Interactive dashboard elements

## 🎯 Project Objectives

- Analyze mobile phone sales performance.
- Compare sales across different brands.
- Understand monthly sales trends.
- Analyze customer ratings and demographics.
- Identify popular payment methods.
- Present business insights using interactive visualizations.
